# 升级到 0.1.0（首个版本）

> 日期：2026-09-06 ｜ 摘要：motex-web-core 首个发布——cordis 声明式装配的 Web 前台框架核心。

## 能力基线（0.1.0 包含）

- 纯服务端渲染全家桶：server（HTTP+WS）/ router / page（页面+区块）/ render / asset /
  session（HMAC 签名 cookie）/ i18n / theme（布局=服务）/ manage（后台）
- cordis.yml 声明式装配（DSH 格式）+ `cordis:include` 组合 + `--watch` 热更新
- 双重自检（main 路径 + cordis 装配链路）+ 示例站 + 文档

## 破坏性改动

不适用（首个版本）。

## 从「手动编写的前端项目」迁移

非本框架项目迁移到此版：把页面/路由/会话逻辑改写成 cordis 插件形式
（一个插件文件 = 一个站点），按 README「各项目使用方式」装配。
