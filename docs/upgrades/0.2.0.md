# 升级到 0.2.0（共享核多站点）

> 日期：2026-09-06 ｜ 摘要：单进程挂载多站点（host 模式）——站点插件零改动接入共享 cordis。

## 改动清单

### 新增
- `mountSite(hostCtx, cfg)` / `loadSitePlugin()`：在唯一 cordis 进程内挂载站点——
  业务服务名全隔离作用域（page/router/render/session/i18n/theme/manage/server/m/esc/asset），
  各站点独立端口 listener（请求按作用域分派，互不可见），asset 共享宿主实例
- 站点插件零改动接入：动态 import + 手动 apply（避免 active-fiber 嵌套 plugin 延迟坑）
- `ServerService/PageService/RenderService` 新增 `opts.runtime`（站点作用域运行上下文）；
  `PageService` 新增 `opts.ns`（站点命名空间：page.<id>/page-block.<id> 防站点间同名冲突）
- index.ts 导出 WebConfig/ServerConfig 等配置类型

### 修复
- 示例站 data 改用 `i18n.resolveLang`（宽容 Accept-Language 解析，避免 `*` 等非法 locale 抛错）

## 🔴 破坏性改动

**无**。所有既有 API（页面/区块/路由/会话/i18n/主题/配置/事件）与运行行为不变——
运行期上下文语义对单站点模式保持 root（全局服务视图），与 0.1.1 一致。

## 需要手动操作的事项

- **无需手动操作**。使用共享核是可选能力（由宿主项目调用 mountSite）；独立进程模式不受影响。

## 验证

```bash
npm run self-test && npm run self-test-cordis
```
共享核用法见 [host.ts](../architecture.md#共享核多站点) 与 cordis-local-web 站点 hang 载示例。
