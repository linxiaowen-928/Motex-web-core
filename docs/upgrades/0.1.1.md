# 升级到 0.1.1（运行期上下文 / 端口避让 / 日志）

> 日期：2026-09-06 ｜ 摘要：运行期统一 root ctx；默认端口 18080 + 自动避让；控制台日志挂接。

## 改动清单

### 新增
- **端口避让**：`EADDRINUSE` 时自动 +1 顺延（`server.portAutoShift` 缺省开，
  `server.portShiftLimit` 上限 100）——多项目并存互不冲突
- 控制台日志输出（cordis logger 默认只缓冲；WARN 及以上走 stderr）

### 修复
- 运行期统一 root ctx：中间件/API/页面/区块/布局回调可访问兄弟插件提供的服务
  （此前报 `cannot get property X without inject`）——0.2.0 共享核插件生态的前提

## 🔴 破坏性改动

**`默认端口 8080 → 18080`**（0.1.0 期间变更，本版定稿）：

- **影响**：未在 `web.config.json` 显式配置 `server.port` 的项目，启动端口从 8080 变为 18080
- **处理**：显式配置端口即不受影响；或接受新默认值（18080 是避让链起点，后续版本有端口记忆简化管理）

其余 API/配置格式均无变化。

## 需要手动操作的事项

- 无（仅端口默认值变化；项目若依赖 8080 请显式写回）。

## 验证

npm run self-test && npm run self-test-cordis
